# Coding the Future

> **"Não aguardamos o futuro, nós o programamos."**

Landing page institucional da **Coding the Future**, empresa fictícia de desenvolvimento de software personalizado criada para projeto acadêmico.

## 🌐 Acesso ao Site

O site está publicado e disponível em:
- **GitHub Pages:** **[https://laurastabileofc.github.io/codingthefuture/](https://laurastabileofc.github.io/codingthefuture/)**

---

## 📌 Sobre a Empresa

- **Missão:** Criar soluções tecnológicas de forma criativa e acessível, transformando ideias em projetos reais e facilitando a vida das pessoas através da programação.
- **Visão:** Ser referência no desenvolvimento de software personalizado, consolidando um modelo de gestão que se adapta perfeitamente às necessidades de cada cliente, liderando a inovação com excelência.
- **Valores:** Ética e Integridade, Foco no Cliente, Inovação, Diversidade e Respeito.

### Serviços Oferecidos
- Consultoria e Engenharia de Requisitos
- Arquitetura e Back-end
- Design e Front-end
- Testes e Evolução
- Garantia de Qualidade (QA)

## 🛠️ Tecnologias e Padrões Utilizados

- **HTML5 Semântico:** Estruturação limpa utilizando `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<address>` e `<footer>`.
- **CSS3 Puro:** Layout responsivo com CSS Grid e Flexbox, variáveis padronizadas no `:root` seguindo a paleta oficial da marca e tipografia (`Public Sans` e `Open Sans`).
